# Coder Portfolio Design

This project is a premium coder/developer portfolio website design mockup.

> [!IMPORTANT]
> **Note on Purpose:** This repository is created strictly for **design showcase, demonstration, and practice purposes**. It is **not** my actual live portfolio, but rather a representation of UI/UX design concepts and web development templates.

## 🚀 Features
- **Modern & Premium UI:** Glassmorphism, tailored HSL color palettes, and clean layouts.
- **Interactive Elements:** Smooth animations, hover effects, and responsive navigation.
- **Flask Backend:** Structured backend using Python and Flask to serve pages dynamically.
- **Clean Structure:** Well-organized HTML templates and vanilla CSS/JS styles.

## 🛠️ Tech Stack
- **Backend:** Flask (Python)
- **Frontend:** HTML5, CSS3 (Vanilla CSS), JavaScript

## 📂 Project Structure
- `app.py`: Flask application entry point.
- `templates/`: HTML source files.
- `static/`: Static assets including CSS, JavaScript, and images.
- `requirements.txt`: Python package dependencies.

## ⚙️ Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/barthna/CoderPortfolio.git
   cd CoderPortfolio
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Flask application:
   ```bash
   python app.py
   ```
4. Open your browser and navigate to `http://localhost:5000`.
